# OVERCOOKED WEDDING｜胡闹厨房风格互动婚礼邀请函

一份专为手机设计的互动婚礼邀请函模板。宾客会像接到一张厨房订单一样进入页面：领取婚礼任务、完成限时配餐小游戏、查看婚礼流程与地图，最后提交赴约登记。

项目只使用原生 HTML、CSS 和 JavaScript，不需要前端框架、数据库或服务器。即使完全没有编程经验，也可以只修改一个配置文件，定制成自己的婚礼邀请函。

> 本仓库是可二次定制的公开模板。默认姓名、日期、地点均为示例信息；宾客登记默认仅为本地演示，不会将信息发送到服务器。

## 在线演示

体验页面：[kitchen.joinus.party](https://kitchen.joinus.party/)

该链接仅用于展示页面效果和互动流程。演示中的宾客登记不会上传、通知或汇总为真实宾客名单。

## 页面包含什么

- 手机端沉浸式首页、背景音乐与开场动画
- 婚礼订单、角色来电、时间轴、倒计时与地图导航
- 限时配餐小游戏与祝福彩蛋
- 宾客姓名、联系方式、人数、住宿、接送与留言登记演示
- 微信及社交平台分享标题、描述和封面图配置

## 先说清楚：演示版不会收集宾客信息

信息登记只会保存在填写者当前设备的浏览器中，不会上传到服务器、不会发送给新人，也不提供管理后台或导出功能。清除浏览器的网站数据后，该演示记录会一并删除。

## 三分钟开始

1. 点击 GitHub 页面右上方 **Code**，选择 **Download ZIP** 并解压。
2. 打开 `public/config.js`，只替换引号里的示例文字。
3. 重点修改姓名、日期、地点、地图链接、流程和祝福文案。
4. 双击 `public/index.html` 即可在浏览器预览静态页面。
5. 手机上检查无误后，再按 [完全零基础定制教程](./GUIDE.zh-CN.md) 发布。

## 发布成网址

### 方式一：让 AI 工具帮你发布

适合不想处理 Git、域名和部署命令的用户。将项目文件夹交给支持网页发布的 AI 工具，并要求它生成可分享的 HTTPS 地址。步骤、提示词和排错清单见 [AI 发布教程](./AI_PUBLISH_GUIDE.zh-CN.md)。

### 方式二：GitHub Pages

首次发布时，进入 **Settings → Pages**，在 **Build and deployment** 中选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)`，然后保存。根目录的跳转页会自动打开 `public/` 中的邀请函；以后每次推送到 `main` 都会自动更新。

发布完成后，页面地址为：`https://mastrena.github.io/overcooked-wedding-invitation/`。完整的逐步操作、更新和排错说明见 [完全零基础定制教程](./GUIDE.zh-CN.md#八发布成网址)。

## 做好以后，怎么分享给亲友

请发送部署后的 HTTPS 网址，不要发送电脑上的 `index.html`、`localhost` 或仓库链接。推荐先找 2～3 位亲友分别在 iPhone 和 Android 上测试，再在微信发送链接和二维码。完整步骤见 [分享与发布前检查](./SHARE.zh-CN.md)。
